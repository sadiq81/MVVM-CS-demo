D. Naming conventions

The systematic naming differences between targets are intentional and follow from each target’s architecture:

Layer
UIKit
Mixed
SwiftUI
View models
Protocol + impl: …ViewModelType
Concrete …ViewModel
Concrete …ViewModel
Coordinators
…Coordinator
…Coordinator
— (path-based …Destination)

View models — UIKit exposes each view model behind a …ViewModelType protocol (resolved via DI). SwiftUI & Mixed use concrete …ViewModel classes: SwiftUI’s @ObservedObject / @StateObject can’t be backed by a protocol, so the Type suffix is intentionally UIKit-only.

Coordinators — now uniformly named …Coordinator (no Type suffix) across UIKit & Mixed; SwiftUI uses path-based …Destination routing instead of coordinators.
